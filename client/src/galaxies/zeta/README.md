# ZETA — CONTROL / Integrity

ZETA is the integrity galaxy inside ZCOS. CONTROL is its Console. Integrity is its specialized Desk.

Shared domains: Identity, Memory, Knowledge, Apps, Desk, Settings, Portal.

Locked Dock: Chat · Upload · Logs · Diagnostics · Monitoring.

ZETA may detect and surface system conditions; ZCOS remains the system-wide authority for authorization and cross-galaxy response.
